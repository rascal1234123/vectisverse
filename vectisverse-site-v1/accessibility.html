Accessibility at VectisVerse

We want the VectisVerse website to be usable by as many people as possible.

Interim accessibility statement

This page is currently a concise interim statement. A detailed accessibility audit, conformance position and known-issues list will be added as the website’s content and functionality are completed.

What we are working towards

  • Clear page structure and consistent navigation.
  • Keyboard access with visible focus indicators.
  • Meaningful text alternatives for informative imagery.
  • Responsive layouts for mobile, tablet and desktop screens.
  • Support for visitors who prefer reduced motion.

Tell us about a problem

If you encounter an accessibility barrier or need information in a different format, email contact@vectisverse.com. Please tell us which page you were using and what went wrong.
