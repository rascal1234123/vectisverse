Vectis Concepts – Additional Concept Boards

Eight self-contained layered SVG files and matching PNG previews.
Canvas: 750 × 511 px.
Layers: four named visual regions plus a hidden guides layer.
Compatibility: modern browsers, Inkscape, Affinity Designer, Adobe Illustrator (embedded raster artwork).

The artwork is intentionally preserved as embedded PNG regions, matching the construction method of the supplied existing layered SVG assets.
